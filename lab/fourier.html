Fourier panel

The Fourier Epicycles artifact's Tool view as a panel any Signoff tool can drop in: assets/fourier.js. No tool uses it yet. This page has the tools' CSP and the suite's styles, so what works here works there.

Theme

Defaults

With options

2D and 3D only, opening on 3D, the trefoil knot as floor and wall circles, a centered heart, and the series hidden to start. It's a second panel on the page, too.

Embed

<script src="../signoff/assets/fourier.js"></script>
<div data-signoff-fourier data-mode="2d"></div>

// or, from a tool's own script:
const panel = SignoffFourier.mount(el, { mode: '3d', curve: 'torus' });
panel.setMode('1d'); panel.reset(); panel.destroy();

Every option is listed at the top of assets/fourier.js. 3D loads assets/vendor/three.min.js (three.js r128) the first time a panel shows it.
