History lab

A prototype of the history panel each tool would get. It shows one review, the Smart Thermostat's Main PCBA, with made-up changes. A run of changes by one person folds into one block; open it to see each change, or click a block or a change to view it.

Conflict copies (the dashed lane): when two people edit the same Scribe section from the same version, the newer edit becomes the section and the older one is kept beside it as a copy, so no text is lost. Nothing merges on its own. Pick the copy's block, then Add checked to section (choose its sentences), Use the copy instead, or Delete copy. Each one deletes the copy, which ends the branch. Resolved by Morgan shows the same branch resolved by hand. The design and the survey behind it are in signoff/docs/history.md.
