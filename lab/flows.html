How the suite fits together

A lab for showing how the Signoff tools pass data to each other and keep track of a whole project. Five ways to draw the same picture, all over the made-up Smart Thermostat demo (Acme Climate). Click a tool, a part, or a line to see what moves along it. The code is the hub's Tool Structure page (assets/structure.js), which offers every view but the Project tree. Reads and writes nothing; the review numbers come from Signoff PL's demo snapshot.
